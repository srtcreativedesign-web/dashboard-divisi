# Standard Operating Procedure (SOP): Admin Accounting

## 1. Kegiatan Harian (Daily Checklist)
1. **Pagi (Shift 1 Handovers)**:
   - Ambil data penjualan POS Kysoft dan setoran tunai Shift 1.
   - Input nominal setoran ke menu **Pemasukan & Operasional**.
2. **Sore (Shift 2 Handovers)**:
   - Ambil setoran tunai Shift 2.
   - Rekonsiliasi transaksi QRIS dan EDC dengan laporan terminal merchant.
   - Input semua pengeluaran operasional outlet dan berat laundry hari itu.
3. **Pencatatan Log Kursi & CCTV**:
   - Salin lembar kertas catatan kursi (Utilisasi kursi) ke menu **Audit CCTV & Okupansi Kursi**.
   - Bandingkan dengan log CCTV untuk memastikan tidak ada pemijatan ilegal (pijat tanpa invoice).
4. **Log Stok**:
   - Hitung stok sisa (Stock Opname harian) minyak, krim, dan bahan minuman gratis, lalu input ke menu **Persediaan & Stok**.

## 2. Kegiatan Mingguan (Weekly Checklist)
1. **Validasi Laundry**:
   - Cocokkan invoice fisik dari agen laundry dengan total berat kg yang diinput harian.
   - Tandai tagihan laundry sebagai "Sudah Dibayar" jika sudah divalidasi.
2. **Rekonsiliasi Pasokan Gudang**:
   - Verifikasi dokumen pasokan masuk (Faktur) dari Gudang Pusat dan input ke menu **Pasokan Masuk**.

## 3. Kegiatan Bulanan (Monthly Closing)
1. **Kalkulasi Komisi & Gaji Karyawan**:
   - Periksa kebenaran input rekap durasi pelayanan terapis selama periode 26 hingga 25 bulan berjalan.
   - Run kalkulator komisi pada menu **Komisi & Bonus** untuk menghasilkan slip bonus bulanan terapis.
2. **Eksport Laporan (Monthly Pack)**:
   - Unduh bundel laporan penutupan bulan (Excel) untuk diajukan ke Manager ACC untuk proses persetujuan (approval).
